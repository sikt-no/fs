Terminal med agent team i Claude-panelet. «Utfør med team» i Spesifikasjoner, «Verifiser i terminal med agent team» ved «Verifiser», og «I terminal med agent team» i «Verifiser»-menyen på et krav starter interaktiv Claude Code med agent teams i en terminal i panelet. Der kan Claude dele arbeidet på flere teammates, for eksempel én per feature-fil med `fs-verify-agent-teams`. Du svarer på spørsmål og godkjenner verktøykall i terminalen. Terminalen kommer tilbake etter en omlasting, og «Stopp» avslutter den.
