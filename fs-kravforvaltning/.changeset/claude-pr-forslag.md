Claude-panelet foreslår en PR når du ber om det, eller når Claude har endret krav-filer. Forslaget vises som et kort i svaret med tittel, gren, beskrivelse og filene med endringene, og «Åpne i «Lag PR»» åpner «Lag PR» med filer, tittel, branch og beskrivelse fylt ut. Du ser over og sender PR-en selv. Filer utenfor `krav/` (for eksempel i `tasks/`) kan ikke sendes herfra, og vises på kortet som filer som ikke kan tas med.
