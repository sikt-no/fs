# Veikart (under avvikling)

Prosessen og oppgavemappene er flyttet til [`../tasks/`](../tasks/) — se [`../tasks/README.md`](../tasks/README.md) for struktur, domener, faser og review-for-improvement. Malene ligger i [`../tasks/mal/`](../tasks/mal/).

`opptak/` og `utdanning/` har fortsatt gammel struktur (`<team>/oppgaver/<slug>/`) inntil de teamene migrerer selv. Når de er flyttet, fjernes denne mappa.
